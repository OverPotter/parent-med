# Design Assets

This directory is organized into three groups:

- `brand/` — PillPath logo assets and visual direction boards.
- `guides/` — text design references and design system notes.
- `screens/pillbox/` — pillbox UI reference screens.

## Brand

- `brand/pillpath-logo-v3.png` — main V3 logo asset.
- `brand/logo-specification.txt` — logo style notes and palette details.
- `brand/clarity-energy-v3.png` — V3 visual direction board.
- `brand/clarity-energy-light-v3.png` — light-mode variant of the visual direction board.

## Guides

- `guides/visual-system.txt` — merged app-wide visual token and theme reference.
- `guides/pillbox-guide.txt`

## Screens

- `screens/pillbox/` — grouped pillbox design references with normalized file names.
